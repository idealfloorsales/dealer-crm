# IDEAL AI — безопасный старт

## Состояние
Техническая заготовка API создана, но **модель не подключена** и **ИИ ещё не работает**. По умолчанию IDEAL_AI_ENABLED не задан и статус показывает выключенный режим.

## Ограничения первой версии
- Только чтение. Никаких операций записи или удаления.
- Только авторизованные пользователи CRM.
- Доступ к данным — только через специально созданные серверные инструменты, проверяющие роль, scope и permissions.
- Нельзя передавать модели MongoDB URI, JWT, пароли, внутренние секреты или всю базу целиком.
- Ограничение частоты запросов, аудит без сохранения секретов, лимиты расходов.
- Внешний API модели и трансграничную передачу персональных данных подключать только после согласования правил обработки данных.
- Никакого прямого исполнения сгенерированных ИИ MongoDB-запросов.

## Последующие шаги
1. Проверить, что новые API маршруты закрыты общей JWT-проверкой и не доступны без токена.
2. Определить разрешённые аналитические запросы (например, агрегаты продаж, дилеры с падением продаж) с проверкой прав.
3. Добавить изолированный провайдер ИИ с тайм-аутами, защитой от prompt injection и логированием без персональных данных.
4. Разработать UI чата для ПК и телефона.
5. Протестировать разграничение ролей, отсутствие изменений базы и аварийное отключение ИИ.
6. Отдельно вернуться к MongoDB backup, restore rehearsal и законности хранения данных до включения продуктивных AI-инструментов.
